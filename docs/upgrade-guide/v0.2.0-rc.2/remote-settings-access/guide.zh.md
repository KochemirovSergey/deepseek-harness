# 远程设置访问

[English](guide.md) | 中文

## 变更

远程 Web 页面不再仅因浏览器使用外部主机名而禁用 Host 设置。页面在加载设置前检查 `settings.access()`。获准后，代码工作工具和预览版说明确认等偏好会持久化到所连接的实例，与回环 Web 和桌面端一致。显式内存模式的消费者仍只保留进程内状态。

Client 和 Host 必须同时支持新的访问方法。方法不受支持时拒绝设置访问，不回退到主机名检查。受限实例保留服务器端写入禁令。部署认证和基于角色的路由仍负责选择管理实例或隔离的用户实例；新方法不分配账号角色。

## 迁移

1. 同时更新 Host 和浏览器构建产物；不要仅把设置 UI 包部署到旧 Host 上。
2. 保留浏览器认证、来源检查、部署角色路由和受限实例策略。不要为了让设置可用而暴露未经认证的内部 Host 端口。
3. 重新加载浏览器，通过现有部署入口登录，然后打开设置 → 模型。确认获准实例的设置能够加载，并确认一个无害偏好在刷新后仍然保留。原先仅在远程浏览器进程内保存的偏好不会迁移；如有需要，请重新选择。
4. 确认未认证请求和受限实例写入仍被拒绝。无需迁移设置文件或 Session 数据。
